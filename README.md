# Orbit — Community Hub

A responsive community leaderboard and showcase website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser. No build tools or package installation required.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Your URL will look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Customize the demo content
Open `script.js` and edit the `members`, `showcases` and `staff` arrays near the top.

## Important limitations
This starter site is static. Changes made to the JavaScript data require editing the files and publishing a new commit. It does not include real user accounts, live submissions, private staff permissions, or a database. Do not put passwords, private member information, or secret credentials in these files.
